# TaskFlow - Task Manager App

A full-stack Task Manager web application built using MERN Stack.

## Features

* User Authentication
* Create Tasks
* Update Tasks
* Delete Tasks
* Responsive UI
* Backend API Integration

## Tech Stack

### Frontend

* React.js
* Vite
* CSS

### Backend

* Node.js
* Express.js
* MongoDB

## Project Structure

taskflow-task-manager/
│
├── frontend/
├── backend/
├── package.json
└── README.md

## Installation

### Clone Repository

```bash
git clone https://github.com/sudha09-git/taskflow-task-manager.git
```

### Install Dependencies

```bash
npm install
cd frontend
npm install
cd ../backend
npm install
```

### Run Project

Frontend:

```bash
cd frontend
npm run dev
```

Backend:

```bash
cd backend
npm start
```
